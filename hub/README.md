# 日記ハブ(いまの「日記の記録」スプレッドシートとの同期)

ホーム画面の日記アプリと、いまの「日記の記録」スプレッドシートをつなぐ受け口です。費用はかかりません。

- 記録は今まで通り「日記の記録」の `CoreData` シートに入ります。GASの日記アプリ(元版・縁泉連携v2)もそのまま使えて、どちらで書いた記録も両方に出ます。
- アプリのデータは各端末の中にもあり、圏外でも書けます。開いたとき・戻ったとき・書いてから数秒後に、変わった分だけをやり取りします。
- 同じ記録を二か所で直したときは、後から直したほうが残ります。

## スプレッドシートに足されるもの

| 場所 | 中身 |
|---|---|
| `CoreData` の F列「Id」 | 記録ごとの番号。GASの日記アプリは A〜E 列しか見ないので影響しません |
| シート「_同期台帳」 | id, rev(変更の連番), mtime, deleted, hash。同期のための表なので触らないでください |

A〜E列(Date, Time, Text, Feelings, Thinkings)の形は変えません。アプリで記録を消したときは、行を消さずに A〜E を空にします(GASの日記アプリは行番号で編集・削除するので、行がずれないようにするため)。GASの日記アプリや表で直した分は、次の同期で見つけてアプリへ届けます。

## 準備(最初の1回、パソコンで行うのが楽です)

1. https://script.google.com で「新しいプロジェクト」を作ります(名前の例: 日記ハブ)。スプレッドシートに付ける必要はありません。
2. 最初からある `コード.gs` の中身を全部消して、[Code.gs](https://raw.githubusercontent.com/tadamasa/diary-home/main/hub/Code.gs) の中身を貼り、保存します。
3. 上の関数の選択欄で `setup` を選び、「実行」を押します。
   - 権限の確認が出たら、自分のアカウントを選び、「詳細」→「(安全ではないページ)に移動」→「許可」と進みます。自分で作ったスクリプトなので問題ありません。
   - 下の実行ログに「合言葉: …」が出ます。これを控えます。
4. 右上の「デプロイ」→「新しいデプロイ」を開き、種類の歯車から「ウェブアプリ」を選びます。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」を押し、出てきた「ウェブアプリのURL」(`…/exec` で終わるもの)をコピーします。
5. 日記アプリの「設定」→「日記ハブ(同期)」に、URLと合言葉を入れて「接続して同期する」を押します。最初の1回は全部の記録を受け取るので少し時間がかかります。

URLと合言葉を知っている人は日記を読み書きできるので、他の人には教えないでください。

## スクリプトを新しくするとき

Code.gs を貼り替えて保存したら、「デプロイ」→「デプロイを管理」→ 鉛筆の印 → バージョン「新バージョン」→「デプロイ」。URLは変わりません。

## 設定で変えられるもの(スクリプト プロパティ)

| キー | 既定 |
|---|---|
| `SPREADSHEET_ID` | 「日記の記録」(1yVC3q2d…) |
| `ENSEN_SHEET_ID` / `ENSEN_UI_URL` | 縁泉のシートとUI |
| `BOOKS_SHEET_ID` / `READING_APP_URL` | 読書ハブと読書メモアプリ |

縁泉と読書ハブは読むだけで、書き込みません。
